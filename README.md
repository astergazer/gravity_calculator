# 二軸回転装置の有効加速度探索

内枠に固定された点について、72時間の有効加速度を**内枠座標系でベクトル平均し、その大きさ**を目標値に近づける二つの一定回転速度を探索します。Python 3.9以降で動作し、追加ライブラリのインストールは不要です。

## 起動と入力

このフォルダで以下を実行します。

```sh
python3 acceleration_search.py
```

次の順に入力します。複数の数値は空白またはカンマで区切ります。

1. 評価点の内枠座標 `x y z`（mm）。回転軸の交点が原点です。
2. 目標値（g、0以上）。時間平均ベクトルの大きさを指定します。
3. 外枠の回転速度の下限と上限（rpm）。
4. 内枠の回転速度の下限と上限（rpm）。

入力例（実際の条件に置き換えてください）:

```text
評価点 x y z [mm]: 10 20 30
目標値 [g]（平均ベクトルの大きさ）: 0.01
外枠の下限 上限 [rpm]: 1 10
内枠の下限 上限 [rpm]: 1 10
```

反時計回りが正です。「各回転軸の正側から原点を見たとき」の方向で判断します。負の速度も指定でき、下限と上限が同じなら、その軸の速度を固定します。正の範囲を入力すれば正回転のみを探索します。0を含めた範囲では停止も候補になります。極端な速度の除外は、入力する上下限によって指定してください。

結果を画面と `acceleration_result.csv` に出力します。同名ファイルがある場合は `_1` などの連番を付け、既存ファイルを保持します。

## 座標・初期姿勢

PDFの装置図に対応する理想化として、二つの回転軸は直交し、固定された共通原点で交わるものとします。

| 軸 | 初期姿勢での意味 |
|---|---|
| x | 内枠の回転軸。鉛直上向きが正 |
| z | 外枠の回転軸。水平。外枠の正回転を右手則で定める向きが正 |
| y | x, y, zが右手系になる向き |

評価点の座標は**内枠に固定された座標**です。初期状態で内枠と静止座標の向きを一致させ、外枠角度と内枠角度をどちらも0とします。静止座標系の重力は `(-g0, 0, 0)`、`g0 = 9.80665 m/s²` です。添付手書き式の外軸をz軸とする記法を採用しているため、鉛直上向きはx軸に対応します。

外枠の角度をθ、内枠の外枠に対する相対角度をφとすると、内枠から静止座標への回転行列は次のとおりです。

```text
R(t) = Rz(θ(t)) Rx(φ(t))
θ(t) = u t,  φ(t) = v t
u = 外枠の角速度 [rad/s],  v = 内枠の相対角速度 [rad/s]
```

内枠の回転軸自体が外枠とともに回転します。角度の初期値や装置の設置方向を変える機能、軸のずれ、立ち上がり・停止時の加減速はこの版では含めていません。

## 有効加速度と時間平均

添付手書き式の、重力と回転に伴う慣性項の定義を使用します。評価点での枠内相対速度は0です。

```text
a_eff = Rᵀ g - ω × (ω × r0) - α × r0
ω = (v, u sinφ, u cosφ)                 [内枠座標]
α = (0, uv cosφ, -uv sinφ)              [内枠座標]
```

各軸の速度が一定でも、合成角速度の方向が変わるためαの項を含めます。これは点の枠内座標の二階微分ではなく、そこでの重力と慣性力を単位質量あたりの加速度で表した量です。

目的関数は次の絶対誤差です。

```text
T = 259200 s（72時間）
mean_a = (1/T) ∫[0,T] a_eff(t) dt
q = ||mean_a|| / g0
誤差 = |q - 入力した目標値|
```

各瞬間の大きさの平均やRMSは使用しません。位置はmmからmに、速度はrpmからrad/sに変換します。

### 有限時間の解析積分

一定角速度のため、三角関数を解析積分します。72時間を無限時間平均で代用せず、時間刻みを使った積分のエイリアシングも避けます。

```text
C(w) = sin(w T)/(w T),         C(0) = 1
S(w) = (1 - cos(w T))/(w T),   S(0) = 0

mean_x = -g0 C(u) + u² x - 2uv [S(v) y + C(v) z]
mean_y =  g0/2 [S(u+v) + S(u-v)]
          + [v² + u²/2 (1+C(2v))] y - u²/2 S(2v) z
mean_z = -g0/2 [C(u-v) - C(u+v)]
          + [v² + u²/2 (1-C(2v))] z - u²/2 S(2v) y
```

この式では位置はm、角速度はrad/s、平均加速度はm/s²です。実装の戻り値は各成分をg0で割ったg単位です。ゼロ・ほぼゼロの周波数や速度の和・差も、除算エラーと桁落ちを避けて計算します。

## 探索方法と結果の解釈

範囲の中心・隅、速度が0付近になる領域、二つの速度が等しい／逆符号で等しい領域とその近傍、格子点、乱数点を調べます。追加の乱数点数の既定値は4096です。必要なら複数の初期点から局所探索も行います。

目標値を上下から挟む候補が見つかった場合は、その2点を結ぶ線分上で二分法を行います。線分は入力した長方形の速度範囲内に収まり、関数の連続性を利用して目標に近づけます。許容誤差内の1組が見つかれば探索を終了します。複数解の列挙や、最小速度の解の選択は行いません。

絶対許容誤差の既定値は `1e-8 g` です。CSVの状態は次の意味です。

| status | 意味 |
|---|---|
| `target_met` | 計算上の目標との差が指定許容誤差以下 |
| `best_found` | 許容誤差内の解が見つからず、探索した候補のうち最良のものを保存 |

有限の数値探索であり、`best_found` は範囲内での解の不存在や大域最適性の証明ではありません。必要に応じて追加探索点数や乱数シードを変更できます。許容誤差は理想モデルの計算値に対する条件です。

CSVには、外枠・内枠の速度（rpmとrad/s）、平均加速度の3成分と大きさ（g）、目標との差、位置、上下限、評価時間、計算モデル、評価組数と乱数シードを記録します。速度は丸めずに保存し、画面にも十分な桁数を表示します。72時間ではわずかな速度差で平均が変わる場合があるため、再計算にはCSVの値を使用してください。

## コマンドライン指定

全条件を指定すれば対話入力を省略できます。省略した必須条件だけ対話で入力します。

```sh
python3 acceleration_search.py \
  --point-mm 10 20 30 \
  --target-g 0.01 \
  --outer-rpm 1 10 \
  --inner-rpm 1 10 \
  --tolerance-g 1e-8 \
  --samples 4096 \
  --seed 20261113 \
  --output result.csv
```

終了コードは、目標到達で0、未到達だが結果保存済みで2、入力・保存・計算エラーで1、中断で130です。

## 検証

```sh
python3 -m unittest -v
```

独立した回転行列の二階微分による瞬間加速度、数値積分との平均の比較、72時間の既知の周期解、等速・逆符号・ほぼ等速・ゼロ速度、探索、入力エラー、CSVの再計算、既存出力の保持を検証します。
